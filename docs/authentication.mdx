## Bearer token

Every request must include an `Authorization` header:

```
Authorization: Bearer <token>
```

## Caller types

The API has three caller types. Each endpoint declares which callers it accepts.

| Caller | Token | Access |
|--------|-------|--------|
| `user` | Supabase JWT (your login token) | Own data only |
| `internal` | Internal service token | Full access |
| `external` | Partner API key (e.g. n8n) | Partner-scoped access |

Most developers use the **`user`** caller type.

## Getting a user token

1. Log into [gostudio.ai](https://www.gostudio.ai)
2. Open DevTools (F12) → **Application** → **Local Storage**
3. Find the key `sb-<project-ref>-auth-token`
4. Copy the `access_token` value (starts with `eyJ...`)

<Warning>
User tokens expire after ~1 hour. If you get a `401`, grab a fresh token the same way.
</Warning>

## Error responses

If your token is missing or invalid, the API returns:

```json
{
  "status": 401,
  "error": {
    "type": "authentication_error",
    "code": "unauthorized",
    "dev": 40100,
    "message": "Missing or invalid Authorization Bearer token."
  }
}
```
