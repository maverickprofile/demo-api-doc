## How it works

GoStudio uses **opaque cursor tokens** to mark your position in a result set. Every list response includes a pagination block:

```json
{
  "status": 200,
  "data": {
    "data": [ { "id": 101 }, { "id": 100 } ],
    "pagination": {
      "next_cursor": "eyJpZCI6MTAwfQ==",
      "has_more": true
    }
  }
}
```n
Pass the cursor to fetch the next page:

```bash
GET /api/v2/me/generations?cursor=eyJpZCI6MTAwfQ==
```n

## Query parameters

All list endpoints share these parameters:

| Parameter | Type | Default | Max | Description |
|-----------|------|---------|-----|-------------|
| `limit` | integer | 20 | 100 | Results per page |
| `cursor` | string | - | - | Cursor from a previous response |
| `sort` | string | created_at.desc | - | `created_at.asc` or `created_at.desc` |
| `since` | ISO datetime | - | - | Return records created at or after this timestamp |
| `until` | ISO datetime | - | - | Return records created at or before this timestamp |
