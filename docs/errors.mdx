## Common error codes

| Code | HTTP | Type | Message |
|------|------|------|---------|
| `unauthorized` | 401 | authentication_error | Missing or invalid Authorization Bearer token. |
| `forbidden` | 403 | permission_error | You do not have permission for this action. |
| `user_not_found` | 404 | not_found_error | User not found. |
| `job_not_found` | 404 | not_found_error | Job not found. |
| `insufficient_credits` | 402 | billing_error | You do not have enough credits. |
| `rate_limited` | 429 | rate_limit_error | You are doing that too often. Please wait. |
| `invalid_input` | 400 | validation_error | Some information is invalid. |
| `missing_required_field` | 400 | validation_error | Required information is missing. |
| `invalid_image_url` | 400 | validation_error | The image URL is not reachable or valid. |
| `invalid_model_key` | 400 | validation_error | The model key is not valid for this tool. |
| `content_filtered` | 422 | provider_error | Could not generate this image. |
| `generation_timeout` | 504 | provider_error | The request took too long. Please try again. |
| `internal_error` | 500 | system_error | Something went wrong on our end. |

## Dev codes

Every error also includes a `dev` field — a 5-digit code that maps exactly to
the HTTP status category:

- `401xx` → HTTP 401
- `402xx` → HTTP 402
- `403xx` → HTTP 403
- `404xx` → HTTP 404
- `429xx` → HTTP 429
- `500xx` → HTTP 500
