The Watermark Remover API removes watermarks from images using AI. Send an image URL and receive a clean image in the same response.

## Before you start

- You need a valid **Bearer token**. See [Authentication](/docs/authentication).
- You need sufficient **credits**. Check your balance at GET /api/v2/me/credit-balance.
- Your image must be at a **publicly accessible HTTPS URL**.

## 1. Check available models

Fetch the tool info endpoint to see model tiers and credit costs:

```bash
curl https://www.gostudio.ai/api/v2/apps/watermark-remover/info \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## 2. Choose a model tier

| model_id | Quality | Best for |
|----------|---------|----------|
| lite | Standard | Most watermarks, lowest credit cost |
| pro | High quality | Complex or semi-transparent watermarks |
| advance | Best quality | Difficult watermarks, maximum detail |

Start with lite. Only upgrade if output quality is insufficient.

## 3. Submit the image

```bash
curl -X POST https://www.gostudio.ai/api/v2/apps/watermark-remover \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"image_url": "https://example.com/watermarked.jpg", "model_id": "lite"}'
```

```javascript
const res = await fetch('https://www.gostudio.ai/api/v2/apps/watermark-remover', {
  method: 'POST',
  headers: { 'Authorization': 'Bearer YOUR_TOKEN', 'Content-Type': 'application/json' },
  body: JSON.stringify({ image_url: 'https://example.com/watermarked.jpg', model_id: 'lite' })
});
const { data } = await res.json();
console.log(data.output_urls[0]);
```

```python
import httpx
r = httpx.post(
    'https://www.gostudio.ai/api/v2/apps/watermark-remover',
    headers={'Authorization': 'Bearer YOUR_TOKEN'},
    json={'image_url': 'https://example.com/watermarked.jpg', 'model_id': 'lite'}
)
print(r.json()['data']['output_urls'][0])
```

## 4. Read the response

```json
{
  "status": 200,
  "data": {
    "job_id": 12345,
    "status": "completed",
    "output_urls": ["https://r1.gostudio.ai/outputs/clean-image.jpg"],
    "credits_deducted": 1,
    "credit_balance": 41
  }
}
```

| Field | Type | Description |
|-------|------|-------------|
| job_id | integer | Unique ID for this generation. |
| status | string | completed for synchronous responses. |
| output_urls | string[] | CDN URLs for the cleaned images, ready to use immediately. |
| credits_deducted | number | Credits consumed by this request. |
| credit_balance | number | Your remaining balance after this request. |

## 5. Optional - receive results via webhook

Pass a webhook_url in the request body. GoStudio will POST the result to your endpoint on completion.

```json
{
  "image_url": "https://example.com/watermarked.jpg",
  "model_id": "lite",
  "webhook_url": "https://your-app.com/webhooks/gostudio"
}
```

Your server must respond with HTTP 2xx within 10 seconds to acknowledge receipt.

## 6. Poll job status

```bash
curl https://www.gostudio.ai/api/v2/apps/watermark-remover/12345 \
  -H "Authorization: Bearer YOUR_TOKEN"
```

## Common issues

| Symptom | Likely cause | Fix |
|---------|-------------|-----|
| 401 unauthorized | Token expired | Get a fresh token from browser DevTools |
| 402 insufficient_credits | Balance is zero | Purchase credits in your GoStudio account |
| 400 invalid_image_url | URL not publicly accessible | Ensure the image URL requires no authentication |
| 422 content_filtered | AI rejected the image | Try a different image or a higher model tier |
| 504 generation_timeout | Provider timeout | Retry the request after a short delay |
